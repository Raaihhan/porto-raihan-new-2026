# Muhammad Raihan Portfolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-ready, responsive single-page portfolio that matches the latest supplied design and uses Raihan's CV as the factual source of truth.

**Architecture:** Use a small Next.js App Router application with server-rendered content, one client-side mobile navigation component, typed static portfolio data, and reusable section components. Tailwind CSS provides the responsive visual system; Vitest and Testing Library verify visible content, links, and mobile navigation behavior.

**Tech Stack:** Next.js 15, React 19, TypeScript 5, Tailwind CSS 3, Vitest, Testing Library, jsdom

**Spec:** `docs/superpowers/specs/2026-09-04-portfolio-design.md`

## Global Constraints

- Treat `CV_Muhammad Raihan N.pdf` as the source of truth for every personal fact.
- Treat `images/deisgn website.png` as the primary visual reference and `MOCKUP_DESIGN.md` as the full-page structural reference.
- Use Next.js App Router, TypeScript, and Tailwind CSS without a backend, CMS, database, UI framework, state library, icon library, or animation library.
- Do not mention a design inspiration, add a watermark, or add unsupported metrics, claims, employers, dates, technologies, or outcomes.
- Use `images/Muka.png` as the hero portrait and omit the unsupported `2+`, `5+`, and `100%` statistics.
- Keep section labels and summaries in Indonesian while preserving detailed experience and project bullets in English.
- Support mobile below 768px, tablet from 768px through 1023px, and desktop at 1024px and above without horizontal overflow.
- Maintain semantic landmarks, correct heading order, keyboard access, visible focus, meaningful alt text, and sufficient contrast.

## File Structure

- `package.json`: scripts and pinned runtime/test dependencies.
- `package-lock.json`: reproducible dependency graph generated by npm.
- `next.config.ts`: minimal Next.js configuration.
- `tsconfig.json`: strict TypeScript and App Router aliases.
- `postcss.config.mjs`: Tailwind and Autoprefixer pipeline.
- `tailwind.config.ts`: content paths, brand colors, shadows, and typography tokens.
- `eslint.config.mjs`: Next.js ESLint flat configuration.
- `vitest.config.ts`: jsdom test environment and path aliases.
- `vitest.setup.ts`: Testing Library matchers and cleanup.
- `src/app/layout.tsx`: metadata, font, and document shell.
- `src/app/page.tsx`: page composition only.
- `src/app/globals.css`: Tailwind directives and global interaction/accessibility rules.
- `src/data/portfolio.ts`: typed CV-derived content and navigation data.
- `src/components/icons.tsx`: dependency-free accessible/decorative SVG icons.
- `src/components/navbar.tsx`: the only client component; responsive navigation state.
- `src/components/portfolio-sections.tsx`: reusable section heading, cards, timeline, hero, CTA, and footer.
- `src/__tests__/portfolio.test.tsx`: CV content, sections, assets, and link behavior.
- `src/__tests__/navbar.test.tsx`: keyboard-accessible mobile navigation behavior.
- `public/images/raihan-portrait.png`: copied from `images/Muka.png`.
- `public/cv/muhammad-raihan-cv.pdf`: copied from `CV_Muhammad Raihan N.pdf`.

```tsx
import userEvent from "@testing-library/user-event";
import { Navbar } from "@/components/navbar";

describe("Navbar", () => {
  it("opens and closes the mobile navigation accessibly", async () => {
    const user = userEvent.setup();
    render(<Navbar />);
    const toggle = screen.getByRole("button", { name: /buka menu navigasi/i });

    expect(toggle).toHaveAttribute("aria-expanded", "false");
    await user.click(toggle);
    expect(toggle).toHaveAttribute("aria-expanded", "true");
    const mobileNavigation = screen.getByRole("navigation", { name: /navigasi seluler/i });
    expect(mobileNavigation).toBeVisible();

    await user.click(within(mobileNavigation).getByRole("link", { name: "Tentang" }));
    expect(toggle).toHaveAttribute("aria-expanded", "false");
  });
});
```
