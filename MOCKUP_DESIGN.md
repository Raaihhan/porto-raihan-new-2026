## Mockup Design Reference
Use the provided portfolio mockup image as the **main visual reference** and the CV as the **main content reference**. If there is any conflict, use the CV for factual data and the mockup for layout/style direction.

## Core Instruction
Recreate a **clean, premium, corporate-style personal portfolio website** for **Muhammad Raihan Nur Rizqi Amin** with a strong **backend developer** positioning. The final result should visually feel modern, structured, and professional, with a financial/corporate tone, but **must not mention** inspiration from any bank and **must not contain any watermark**.

## Visual Style
- clean and elegant interface
- dominant colors: white, navy, royal blue, light gray
- small gold/yellow accent allowed only as a subtle decorative accent
- modern sans-serif typography
- rounded cards
- subtle border and shadow
- large hero section
- spacious layout with strong alignment and visual hierarchy
- premium corporate feeling
- no excessive ornament
- no dark-mode-only layout

## Page Structure
Build the portfolio as a **single-page website** with these sections in order:

1. **Navbar**
2. **Hero**
3. **About**
4. **Skills**
5. **Experience**
6. **Education**
7. **Certification**
8. **Projects**
9. **Contact CTA**
10. **Footer**

- Left side: name / portfolio branding
- Center or right: navigation links:
  `Beranda`, `Tentang`, `Pengalaman`, `Proyek`, `Pendidikan`, `Kontak`
- Right side CTA button:
  `Hubungi Saya` or `Unduh CV`

The hero should be the strongest visual section.
- Two-column desktop layout
- Large bold headline introducing Raihan as a Backend Developer
- Short supporting paragraph about backend systems, banking solutions, service integration, reliability, and digital solutions
- CTA buttons:
  `Lihat Proyek`
  `Hubungi Saya`
- Display contact/social links such as email and LinkedIn
- Include a professional portrait/photo area
- Optional decorative city/building background or corporate visual styling, but keep it subtle and clean

## Layout Behavior
- Desktop: multi-column with clear spacing and card-based layout
- Tablet: reduce columns cleanly
- Mobile: single-column layout with preserved spacing and readability
- Avoid horizontal scroll
- Keep buttons and touch targets usable

## Content Accuracy
Use the CV as source of truth for:

## Final Standard
The result should look like a polished real portfolio landing page suitable for a backend developer, with a refined Indonesian corporate style, clean component hierarchy, and professional presentation quality.
